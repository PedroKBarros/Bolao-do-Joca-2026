# Sigeb BolaXo

## Sobre

Sigeb BolaXo ou Sistema de Gestão de Bolões BolaXo é um software desenvolvido para a gestão de bolões que ocorrem em território brasileiro.

Aviso: Sigeb BolaXo não incentiva a prática de bolões não autorizados por autoridade competente, tendo-se em vista que tais bolões podem violar a legislação vigente na República Federativa do Brasil.
