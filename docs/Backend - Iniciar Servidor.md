# Iniciar Servidor Backend

## Sem nodemon:
No terminal, acesse a pasta /backend e execute:
```
node src/server.js
```

Se o servidor for iniciado corretamente deverá aparecer no terminal:
```
Servidor rodando na porta 3000
```

## Com nodemon:
O nodemon permite que o servidor não precise ser reiniciado toda hora.
Obs.: ele já está instalado.

No terminal, acesse a pasta /backend e execute:
```
npm run dev
```
Se o servidor for iniciado corretamente deverá aparecer no terminal:
```
Servidor rodando na porta 3000
```
